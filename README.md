# I321-Anthony_Viktoriia

Description : 
Pizza du Jour - Backend API

Bienvenue dans le projet Pizza du Jour ! Cette application backend permet de gérer et d'afficher une pizza spéciale pour chaque jour de la semaine. 
L'objectif de ce projet est de proposer une expérience dynamique aux clients d'une pizzeria. Plutôt que d'avoir une carte fixe, le backend change automatiquement la pizza mise en avant selon le jour actuel, avec son prix et ses ingrédients

Fonctionnalités :

Sélection Automatique : Affiche la pizza correspondant au jour de la semaine (Lundi, Mardi, etc.)
Gestion des Ingrédients : Liste détaillée des composants et du prix pour chaque recette
API REST : Routes simples pour récupérer le menu complet ou la pizza du moment

Installation : 

Cloner le dépot : https://github.com/Anthony10012/I321-Anthony_Viktoriia
Changer la branche main en develop de git, pour ça fait lancer la commande suivant "git switch develop"
Installer les dépendances en lancement la commande suivant "npm install" et puis "npm start" pour lancer le projet
